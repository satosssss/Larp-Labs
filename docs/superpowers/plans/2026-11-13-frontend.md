## Review Focus

- Edited sample text must invalidate explanations instead of retaining misleading content.
- Real upload after sample must clear all previous document data.
- Stale analysis response must not populate a different document/revision.
- Language switching must preserve user questions, checklist and chat history.
- Narrow screens and enlarged text must keep primary controls and help usable.
